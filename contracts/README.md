# Contracts

The only files `api/` and `web/` share.

- `openapi/workouterr.json`: the OpenAPI document, generated by the API and committed. The Angular app generates its
  types and zod schemas from it. Never edited by hand.
- `domain-cases/`: JSON test cases (input, expected output, description) for the domain rules, run by both the C#
  and the TypeScript tests. Change the cases first, then the implementations.
